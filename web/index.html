앱 업데이트

저장소 파일과 로컬 수정 내용은 변경하지 않습니다. 열어둔 저장소와 작성 중인 커밋 메시지는 다시 열 때 복원합니다.

실행 환경 · SSH

필요한 프로그램 설치

Windows는 WinGet으로 지정한 사용자 폴더에 설치합니다. 기존 설치가 있으면 해당 경로를 연결하세요. WSL은 Ubuntu/Debian 패키지 관리자로 Python·Git·OpenSSH를 설치합니다.

SSH 키 관리

경로는 선택한 환경 기준입니다. 기존 키의 암호는 해당 환경의 ssh-agent에서 해제하세요. 호스트 키 확인은 유지합니다.

새 Ed25519 키 생성

~/.ssh/branchdesk-이름/id_ed25519에 생성합니다. 같은 이름의 키는 덮어쓰지 않습니다. 암호가 있는 키가 필요하면 터미널에서 ssh-keygen으로 생성한 뒤 경로를 연결하세요.
