실행 환경

실행 환경 추가

Git·Python이 없나요? 프로그램 설치

Windows는 지정한 사용자 폴더에 설치합니다. WSL2는 Ubuntu/Debian 배포판의 패키지 관리자로 설치합니다.

SSH 키 연결 · 관리 (선택)

경로는 선택한 환경 기준입니다. 기존 키의 암호는 해당 환경의 ssh-agent에서 해제하세요. 호스트 키 확인은 유지합니다.

새 Ed25519 키 생성

~/.ssh/branchdesk-이름/id_ed25519에 생성합니다. 같은 이름의 키는 덮어쓰지 않습니다. 암호가 있는 키가 필요하면 터미널에서 ssh-keygen으로 생성한 뒤 경로를 연결하세요.

앱 시작 설정 (고급)

앱 자체를 시작할 환경입니다. 저장소마다 사용할 Windows·WSL2 선택과는 별도이며, 일반적인 사용에는 변경할 필요가 없습니다.
